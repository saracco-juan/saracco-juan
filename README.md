I started by shipping pixel-perfect email campaigns to millions of users, moved on to owning the frontend of a critical module in an enterprise ERP, and now build full products end to end, from the React UI to the API and the CI pipeline.

### ◉ How I work

- **End-to-end ownership.** I take a feature from UI to API to deployment, and I unblock myself by mocking backend contracts instead of waiting.
- **Quality gates.** Unit tests, Storybook, and CI with a SonarCloud quality gate and coverage, so regressions are caught before merge.
- **AI agents, spec first.** I use AI agents in a spec-driven, context-first workflow: clear context and written specs before code, for consistent results.
