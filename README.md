### ◉ Liner notes

**From pixel-perfect UIs to scalable architectures.** I'm Juan Saracco, a Software Engineer based in Buenos Aires. I specialize in building end-to-end applications using React and TypeScript. My journey spans from optimizing UI components for millions of global users to owning the frontend of critical enterprise ERP modules. Currently, I'm highly focused on bridging scalable interfaces with **AI integrations** (LLMs, agents).

I'm looking for **Software Engineer / Front-End roles**, especially those open to AI-driven product development. Open to remote work. Argentine and Italian citizen (EU work eligibility).

### ◉ How I work

- **End-to-end ownership.** I take a feature from UI to API to deployment, and I unblock myself by mocking backend contracts instead of waiting.
- **AI-Driven workflows.** I use AI agents in a spec-driven, context-first workflow (clear context and written specs before code) and actively look to integrate LLM capabilities into interfaces.
- **Quality gates.** Unit tests, Storybook, and CI with a SonarCloud quality gate and coverage, so regressions are caught before merge.
